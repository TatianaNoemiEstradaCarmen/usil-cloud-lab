Cloud Computing

Una introducción a la computación en la nube: recursos digitales disponibles bajo demanda para crear, almacenar y ofrecer servicios con flexibilidad.

Conoce más ↓

¿Qué es la computación en la nube?

Es el acceso a recursos informáticos —como servidores, almacenamiento, redes y software— a través de internet. En lugar de administrar toda la infraestructura localmente, una organización puede utilizar servicios de un proveedor cloud y ajustar su capacidad según sus necesidades.

☁️

Acceso bajo demanda

Los recursos se solicitan cuando hacen falta y pueden administrarse desde distintos lugares con conexión a internet.

📈

Escalabilidad

La capacidad puede aumentar o disminuir para responder a cambios en la actividad y la demanda.

🧩

Servicios gestionados

El proveedor opera parte de la infraestructura, mientras el equipo se concentra en sus aplicaciones y datos.

Modelos de servicio

Los servicios cloud se suelen agrupar según el nivel de control y administración que recibe el cliente.

IaaS

Infraestructura como servicio. Ofrece recursos virtualizados, como máquinas, redes y discos. El cliente administra el sistema operativo y sus aplicaciones.

PaaS

Plataforma como servicio. Proporciona un entorno administrado para desarrollar y desplegar aplicaciones sin gestionar directamente toda la infraestructura.

SaaS

Software como servicio. Permite utilizar aplicaciones listas a través de internet, normalmente desde un navegador o una app.

De una idea a una aplicación disponible

Un despliegue con contenedores empaqueta una aplicación y sus dependencias para que se ejecute de manera consistente en distintos entornos.

Crear

Se prepara el código de la aplicación y una receta que describe cómo construirla.

Empaquetar

Docker crea una imagen que puede almacenarse y compartirse en un registro de contenedores.

Desplegar

Una plataforma cloud ejecuta la imagen y puede exponer la aplicación mediante una dirección web.
